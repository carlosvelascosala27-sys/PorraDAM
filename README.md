# Porra DAM 

App Android para hacer una porra de los partidos de liga entre la clase.
Cada jornada, cada persona pronostica el resultado de los partidos; cuando se juegan,
la app compara los pronósticos con los resultados reales, reparte puntos y ordena una clasificación.
No hay dinero de por medio: solo puntos.

Miniproyecto del módulo **Programación Multimedia y Dispositivos Móviles (PMDM)** · 2º DAM · curso 2026-2027.

## Pantallas

| Pantalla | Qué muestra |
|---|---|
| Bienvenida | Elegir alias y código del grupo |
| Jornada | Los partidos de la jornada para poner tu pronóstico |
| Resultados | Resultado real, tu pronóstico y los puntos obtenidos |
| Clasificación | Participantes ordenados por puntos |
| Perfil | Tus datos en la porra |

## Reglas del juego

- Resultado exacto: **8 puntos**.
- Si no es exacto: **+2** por acertar el signo (1, X o 2) y **+2** por cada equipo cuyo número de goles se acierte.
